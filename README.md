# WoW Classic Arena

Личный прототип арены 1 на 1 в духе World of Warcraft Classic: бой против бота или дуэль с другом по сети.

Открыть игру: https://switer92.github.io/wow_classic_arena/

Сетевая игра: один создаёт комнату и говорит код, второй вводит код и нажимает «Войти». Связь идёт напрямую между браузерами через PeerJS. Вкладка того, кто создал комнату, должна оставаться открытой и активной.

Модели, текстуры, иконки и звуки принадлежат Blizzard Entertainment и используются только для личного некоммерческого прототипа.
